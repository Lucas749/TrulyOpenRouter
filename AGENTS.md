# Repository working agreements

- Read `HANDOVER.md` and `docs/POLICIES.md` for architecture, current work, and enforcement boundaries.
- Make small, focused Git commits, one idea per commit. Run checks appropriate to each change.
- Avoid AI assistant or provider branding and attribution in responses, authored project copy, commit messages, and pull request text. Do not add generated-content or coauthor footers.
- Avoid the past-tense form of the verb "call" in authored prose.
- Keep secrets and local runtime files out of Git.
